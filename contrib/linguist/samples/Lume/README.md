# Lume sample provenance

These files are unchanged copies from the Lume project and are staged for a future github/linguist contribution. Their original paths are:

- collections_closures.lume — examples/05_collections_closures.lume
- traits_generics.lume — examples/06_traits_generics.lume
- contracts_defer.lume — examples/07_contracts_defer.lume
- stdlib.lume — examples/09_stdlib.lume

The examples cover collection operations, closures, traits, generic bounds, contracts, error handling, strings, and standard-library use. They are project examples rather than claims of broad external adoption.
